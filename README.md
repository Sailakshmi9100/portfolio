# Sai Lakshmi Vedurupaka - Portfolio

## Files
- `index.html` - complete responsive portfolio
- `Sai_Lakshmi_Vedurupaka_Resume.pdf` - PDF generated from the uploaded resume image

## Run locally
Open `index.html` in a browser.

## Before publishing
Replace the marked placeholder links in `index.html` with:
- LinkedIn URL
- GitHub URL
- College Event Management System live URL
- Project GitHub URL
- NPTEL certificate URL
- EduSkills certificate URL
- SmartBridge certificate URL
- HackerRank profile URL

## Deploy on Vercel
1. Create a GitHub repository.
2. Upload `index.html` and `Sai_Lakshmi_Vedurupaka_Resume.pdf`.
3. Import the repository into Vercel.
4. Deploy with the default settings.
